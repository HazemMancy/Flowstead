**Moving things around, properly**

- **No solve on the first move.** Projects solved before 1.8.8 kept their results current only in memory, so the first symbol you moved after opening one started the active solver. The update is now saved as the project opens, so moving symbols never solves again.
- **Tables stay put.** A stream's or unit's property table keeps its place when you move the object; drag the table itself to move it.
- **Grab small symbols easily.** Starting a drag on a connection point that already has a line now moves the symbol instead of drawing a new connection, so a valve moves wherever you grab it, without "already connected" messages.
