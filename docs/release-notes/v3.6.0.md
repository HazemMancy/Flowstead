**Faster solves**

- Bubble and dew points are no longer calculated at every solve. They were most of a solve's time (four extra flashes per stream). A stream's editor, the results, a table that lists them and the documents ask for them when they are needed, so they still appear wherever they are shown.

**Enthalpy and entropy as HYSYS**

- Enthalpy and entropy now include each compound's heat of formation and absolute entropy, as HYSYS reports them (Peng-Robinson, SRK and Lee-Kesler). Absolute values now compare with HYSYS; differences such as duties are unchanged.
- Fluid package → Enthalpy and entropy switches back to DWSIM's reference. A case that types an enthalpy or an entropy keeps DWSIM's reference unless you change it.
- The choice is saved with the case, so a case opened in Flowstead Web shows the same values.
