**No more overlapping text**

- Phase envelope: the labels of points close together, such as the critical point and the cricondenbar, no longer print on top of each other. Each label moves to a free place next to its point and stays inside the plot.
- Plot legends wrap onto a second row instead of being cut off at the edge of the screen.
- Safety → relief valve → inlet and outlet lines: the length and fittings (equivalent length) fields each have their own row, so the label no longer runs over the field's border. Other number fields keep a long label on one line.
