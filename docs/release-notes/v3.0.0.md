**Flowstead 3.0: now on DWSIM 10**

- Every calculation now runs on **DWSIM 10.2.12**, the current generation of the open-source simulator, built by Flowstead from its published source, on the phone and on the engine server alike. DWSIM 9 receives no more updates; DWSIM 10 brings its fixes and opens the way to its newer features, such as distillation curves and product-quality column specifications, in later versions.
- **Liquid densities are more accurate.** Liquid mixtures (NGL, LNG, condensate, live oil) now use COSTALD, the method HYSYS uses for hydrocarbon liquids; pure and water-rich liquids keep experimental data. Against reference equations of state over 29 liquids the average error is 0.50 % (was 0.87 %) and the worst 1.9 % (was 5.4 %, a hot NGL). Liquid volume flows, separator levels and line sizing follow.
- **PVT laboratory about 100 times faster.** A saturation pressure takes about a second instead of up to two and a half minutes, with the same result. The PVT regression also tries finer steps before stopping, so it fits closer.
- Results change slightly with the new engine: mainly liquid densities and what depends on them (volumes, residence times, reactor conversions in a fixed volume). Every reference check (steam tables, hand calculations, published data) still holds; the details are in the project's decision log (D88–D94).
- **Phases labelled by the fluid, both ways.** A one-phase result is checked against the fluid itself: a dense gas at very high pressure (for example 320 barg) is reported as vapour, and a subcooled liquid that the flash called vapour is reported as liquid.
- Projects from earlier versions open as before, and so do DWSIM files saved by Flowstead 2.x (the nine kept for testing all open and solve). Files exported by 3.0 note that desktop DWSIM's default liquid densities can differ from Flowstead's for mixtures.
