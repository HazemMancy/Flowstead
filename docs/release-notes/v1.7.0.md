**What's new in 1.7.0**

**Help & Resources, as HYSYS's Help and Resources ribbon, and all of it offline.** Open it from the Help icon on the Projects screen or the flowsheet menu, or tap **?** in any editor to go straight to that unit's page, as F1 does in HYSYS.
- **Manual**: getting started, colours and degrees of freedom, stream specifications (vapour fraction, bubble and dew points), the property packages with their equations, every unit operation, the analysis tools, safety and sizing. Search it all.
- **Tutorials**: your first flowsheet, sizing a separator, a relief valve for a separator, a phase envelope with hydrates.
- **Methods reference**: every method Flowstead uses, with how it was checked and how it differs from HYSYS.
- **Data library**: U values by service, separator internals (K factors, inlet devices, nozzle limits, retention times), motor ratings and API driver margins, control valve factors, ASME pipe sizes and utility temperatures, the same values the sizing tools use.
- **Examples**: eighteen ready-made flowsheets, from a JT letdown to a depropanizer, a lean-oil absorber and reactors. Each is one of Flowstead's benchmark cases, checked on every engine change; tap one to open it as a new project.
- **What's new** and **Support** (report a problem, source code, DWSIM's documentation).
