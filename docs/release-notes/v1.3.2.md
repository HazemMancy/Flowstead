**What's new in 1.3.2: results on the object itself, and updates in the app**

- **Streams:** tap a stream to see all of its results there: Overall, then Vapour, Liquid and Aqueous blocks for the phases present (flows, standard flows, molecular weight, density, viscosity, Z factor, Cp, Cp/Cv, thermal conductivity, surface tension, enthalpy, entropy), and the composition of each phase.
- **Equipment:** tap a unit to see every result the engine returned for it, and a worksheet of its inlet and outlet streams side by side (conditions, phase properties, composition), as on HYSYS's worksheet tab.
- **Updates in the app:** Settings → Check for updates → **Update** now downloads the new version inside ThermoDock (with progress, in the background), checks it, and opens Android's install prompt; you tap Update once. The first time, Android asks you to allow ThermoDock to install apps. Coming from 1.3.1 or older, this update itself still downloads through the browser.
