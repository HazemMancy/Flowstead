**Phase envelopes you can trust**

- Phase envelope: for some rich gases and condensates DWSIM traces the bubble and dew curves as two pieces that never meet. The app used to report the end of the bubble curve as the critical point and the cricondenbar, below dew points the PVT laboratory finds. It now says the envelope did not close and shows no critical point, cricondenbar or cricondentherm for it; the curves are still drawn as DWSIM traced them.
- Vapour-fraction (quality) lines: near the critical point DWSIM's flash could give up and return a made-up temperature, which drew a stray line across the plot. Every point is now checked with a second flash, and a line stops where the flash stops working.
