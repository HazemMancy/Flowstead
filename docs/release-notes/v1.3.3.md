**What's new in 1.3.3: Lee–Gonzalez–Eakin gas viscosity**

- **New option:** Fluid package → Vapour viscosity → "Lee–Gonzalez–Eakin (natural gas)", the natural-gas industry's viscosity correlation. Together with "Plain EOS (as HYSYS)" densities it comes within 2 % of HYSYS for a dense natural gas (0.0497 cP against HYSYS's 0.0489, for a C1–C5 gas at 320 barg and 35 °C). The default stays DWSIM's method. Liquid viscosities are unchanged.
- Updates install from inside the app (from 1.3.2 on): Settings → Check for updates → Update.
